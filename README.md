# Business FAQ Chatbot

An AI powered chatbot that automatically answers customer questions for any business.

## Live Demo
   [benjay-faq-chatbot.streamlit.app](https://benjay-faq-chatbot.streamlit.app)

## What it does
- Business owners enter their business info and FAQs
- Customers ask questions and get instant AI responses
- Works for any business, any industry, globally

## Built with
- Python
- Streamlit
- Groq API (LLaMA 3.3 70B)
